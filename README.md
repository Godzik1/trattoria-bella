# Trattoria Bella - Restaurant Demo Site

A demo business card website for a restaurant, built with **Next.js 15**, **Tailwind CSS v4** and **TypeScript**.

## Features

- Interactive menu with category tabs
- Photo gallery with lightbox
- Table reservation form with live availability
- Chef's Special countdown timer
- Customer testimonials
- OpenStreetMap embed
- Fully responsive with mobile burger menu

## Tech Stack

- [Next.js 15](https://nextjs.org)
- [Tailwind CSS v4](https://tailwindcss.com)
- [Lucide React](https://lucide.dev)
- [TypeScript](https://www.typescriptlang.org)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

Deployed via [Cloudflare Pages](https://pages.cloudflare.com).
